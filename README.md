# PrizePicks Bot

Daily NBA PrizePicks player prop analysis powered by a quantitative data pipeline and sharp betting intelligence. Pulls live projections, player stats, matchup data, injury reports, and expert picks — then scores every prop for edge detection.

## Architecture

```
┌─────────────────────────────────────────────────────────┐
│                     run-report.ts                        │
│              (orchestrates full pipeline)                 │
├──────────┬──────────┬───────────┬───────────┬───────────┤
│ PrizePicks│ NBA Stats│  Matchup  │  Injury   │  Expert   │
│  Client   │  Client  │ Analyzer  │  Client   │  Client   │
│ (API)     │ (Python) │           │ (ESPN)    │ (Odds API)│
├──────────┴──────────┴───────────┴───────────┴───────────┤
│                    Pick Scorer                           │
│          (edge detection + confidence rating)            │
├─────────────────────────────────────────────────────────┤
│              SQLite DB (data/fund.db)                    │
│            (pick history + results tracking)             │
└─────────────────────────────────────────────────────────┘
         │
         ▼  JSON output
┌─────────────────────────────────────────────────────────┐
│           OpenClaw AI Agent (cron job)                    │
│  • Reads pipeline data + does web research               │
│  • Finds sharp money signals, line movement              │
│  • Generates final Telegram report                       │
│  • Daily @ noon Pacific | claude-sonnet-4-6 | 900s      │
└─────────────────────────────────────────────────────────┘
```

## Data Sources

| Source | Auth | What it provides |
|--------|------|-----------------|
| [PrizePicks API](https://api.prizepicks.com) | None (free) | Live projections and lines |
| [nba_api](https://github.com/swar/nba_api) (Python) | None (free) | Player averages (L3/L10/season), team stats |
| [The Odds API](https://the-odds-api.com) | API key (free tier) | DraftKings + FanDuel lines, spreads, totals |
| ESPN | None (scraped) | Injury reports |

## Usage

### Run the data pipeline

```bash
source .env && export ODDS_API_KEY
npx tsx run-report.ts
```

This runs the full pipeline:
1. Fetches today's PrizePicks NBA projections
2. Pulls player stats via nba_api
3. Analyzes matchups against opponent defensive rankings
4. Scores each projection for edge and confidence
5. Outputs a JSON/markdown report with top picks, parlay, traps

### AI Report Generation

The final human-readable report is generated by an OpenClaw cron job that:
- Reads the pipeline output
- Does additional web research (sharp money, line movement, capper consensus)
- Delivers a formatted report via Telegram

**Cron config:** daily at noon Pacific, model `anthropic/claude-sonnet-4-6`, timeout 900s.

## Important Rules

- **Filter `odds_type === 'standard'` only** — PrizePicks has standard and demon lines; only standard lines are valid for analysis.
- **Blowout penalty for spreads ≥ 8** — OVER picks in blowout games are penalized because starters get pulled early. The scorer automatically applies this.
